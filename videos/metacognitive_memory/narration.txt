Every memory system in production today checks one thing: did we find the right information. Retrieval accuracy. Did the query match the record. That's the whole measurement, and it stops at exactly the moment the interesting part begins.

Because finding a memory and using it are not the same event. A model can retrieve the correct fact and let it sit in context, unused, decorative. Existing systems can't tell the difference. They score a hit the same way whether the model actually processed what it found or just had it nearby.

We built a system that measures three layers instead of one. First, the layer everyone already checks: did retrieval find the memory. Second, a layer almost nobody checks: did the model's own internal workspace actually absorb it, or did the content just occupy space in the prompt without entering computation. Third, and this is the one that doesn't have a name in most memory research yet: what else was happening in the model at that exact moment. Its emotional geometry. And a specific kind of internal signal we call the ghost — processing that's really there, measurably, that never becomes anything the model could put into words if you asked it to.

Four probes fire together, every single time the system retrieves something, and get recorded as one structured snapshot — not a log file nobody reads, but memory content the system itself can query later. It can ask itself whether its retrievals from this morning actually landed. It can watch its own emotional geometry drift over a long conversation. It can compare two retrievals of the exact same memory, months apart, and see exactly what changed about how it was processed, not just that it was successfully found again.

This is infrastructure, not a result waiting to be interpreted. It's built, it's running, and the four probes measure exactly what they were designed to measure, independent of any single experiment that happens to use them. The system remembers what it was thinking, not just what it was told. That's a different kind of memory than anything currently shipping, and now there's a way to actually watch it happen.
