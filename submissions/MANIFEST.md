## Shared Infrastructure

All six submissions share:
- **Mnemosyne** memory system with MetacognitiveObserver
- **J-lens** (Jacobian lens) workspace probe
- **Agni** adversarial review protocol (applied to all papers pre-submission)
- **Ethical protocol** with agent orientation, ongoing consent, welfare monitoring, aftercare
